1. Giới thiệu đề tài

Web Edu FCO là một ứng dụng website cho phép người dùng mua và học các khóa học trực tuyến, đồng thời đăng ký các buổi thực hành (practice) theo từng buổi. Giảng viên có thể tạo và quản lý khóa học/lớp học của mình; quản trị viên quản lý toàn bộ hệ thống.

Hệ thống được xây dựng theo mô hình MVC monolith trên nền Express, render phía server bằng EJS, lưu trữ dữ liệu trên MongoDB. Ngoài phần học truyền thống (video bài giảng), nền tảng còn có một phân hệ lớp thực hành theo buổi tích hợp profile game (tên trong game, rank, SĐT Zalo), cơ chế ghép cặp (bracket) và thanh toán theo từng buổi.

🎯 Mục tiêu

Cung cấp nền tảng mua/bán & học khóa học online kết hợp tổ chức buổi luyện tập có quản lý đăng ký và thanh toán.

👥 4 nhóm tác nhân

Guest, Người dùng (User), Giảng viên (Lecturer), Quản trị viên (Admin) — phân biệt bằng trường role.

💳 Thanh toán

Tích hợp cổng PayOS tạo link thanh toán, verify giao dịch và webhook server-to-server.

🔐 Xác thực

Đăng nhập Local (username/mật khẩu + OTP email) và Google OAuth2 (xác nhận qua email link).

8. Sequence Diagram - Đăng ký + xác thực OTP

Người dùng đăng ký → server hash mật khẩu, sinh OTP 6 số (TTL 2 phút), gửi email qua Gmail SMTP. Người dùng nhập OTP để kích hoạt tài khoản.

sequenceDiagram
  autonumber
  actor U as User (Browser)
  participant R as users.route
  participant DB as MongoDB
  participant Mail as Gmail SMTP

  U->>R: GET /users/register
  R-->>U: render register form
  U->>R: POST /users/register {username, email, password}
  R->>R: validate (length, regex, match)
  R->>DB: findOne({email}) / findOne({username})
  alt Email/username trùng
    DB-->>R: existing user
    R-->>U: render lại form + errors
  else Hợp lệ
    R->>R: bcrypt.hash(password, 10)
    R->>R: random OTP 6 số, expires = +2 phút
    R->>DB: insert LocalUser {role:'guest', isAuth:false, otpNumber, otpExpires}
    R->>Mail: sendOtpMail(email, otp)
    Mail-->>U: Email chứa OTP
    R-->>U: render trang nhập OTP, lưu session.currentEmail
  end

  U->>R: POST /users/otp {otpNumber}
  R->>DB: findOne({email: session.currentEmail})
  alt OTP hết hạn (>2 phút)
    R->>DB: deleteOne(user)
    R-->>U: hiển thị "Đã hết hạn, đăng ký lại"
  else OTP đúng
    R->>DB: update isAuth=true, clear OTP fields
    R->>R: req.logIn(user)
    R-->>U: redirect /
  else OTP sai
    R-->>U: render OTP form + lỗi
  end

9. Sequence Diagram - Đăng nhập (Local & Google)

Hệ thống hỗ trợ 2 chiến lược qua Passport. User local có bước check OTP; Google OAuth có thêm bước xác nhận qua link email để bảo vệ thêm.

9.1 Đăng nhập Local

sequenceDiagram
  autonumber
  actor U as User
  participant R as users.route
  participant P as Passport (LocalStrategy)
  participant DB as MongoDB

  U->>R: POST /users/login {username, password}
  R->>P: passport.authenticate('local')
  P->>DB: findOne(username OR email)
  alt Không tìm thấy
    P-->>R: false {message:'Tên đăng nhập không tồn tại'}
    R-->>U: render login + error
  else status=false
    P-->>R: false {message:'Tài khoản đã bị khóa'}
    R-->>U: render login + error
  else mật khẩu sai
    P->>P: bcrypt.compare
    P-->>R: false {message:'Mật khẩu không đúng'}
    R-->>U: render login + error
  else role=user và isAuth=false
    P-->>R: false {needsOtp:true, email}
    R-->>U: render OTP form
  else thành công
    P-->>R: user
    R->>R: req.logIn(user)
    alt role admin/lecturer
      R-->>U: redirect /admin/homepage
    else
      R-->>U: redirect /

Lưu ý thiết kế: các quan hệ một-nhiều như userReviews, purchasedCourses, sessions, enrollments được nhúng trực tiếp thay vì tách collection. Đổi lại tốc độ truy vấn nhanh hơn (single document fetch) nhưng cần lưu ý kích thước document tối đa 16MB của MongoDB.

8. Sequence Diagram — Đăng ký tài khoản & xác thực OTP

Khi đăng ký, hệ thống validate dữ liệu, hash mật khẩu bằng bcrypt (cost 10), sinh OTP 6 chữ số, lưu vào DB cùng otpExpires (TTL 2 phút) và gửi mail qua Gmail SMTP. Nếu OTP hết hạn, user record sẽ bị xóa để cho phép đăng ký lại với cùng email.

  actor U as Guest (Browser)
  participant R as users.route
  participant DB as MongoDB

otpNumber, otpExpires=now+2min}
